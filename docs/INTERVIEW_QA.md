# 面试问题参考答案

## 1. 为什么企业需要 Skill，而不是直接使用 ChatGPT？

ChatGPT 提供通用能力，但不理解企业内部数据口径、岗位流程和输出规范。Skill 把企业私有经验和标准工作流固化为可复用、可验证、可治理的能力资产，并能稳定接入企业系统与数据。

## 2. 一个企业岗位 Skill 最重要的组成部分是什么？

输入数据契约和输出结果模板。它们决定了 Skill 能否被稳定调用、结果是否可靠、能否被验证。Agent Prompt 很重要，但只有在契约明确的前提下才有价值。

## 3. 设计“销售分析 AI 员工”需要采集哪些专家经验？

- 销售漏斗各环节的定义与转化口径
- 优秀销售经理的分析框架和复盘步骤
- 常见问题的归因逻辑与对策
- 销售指标的标准计算公式
- 输出报告的格式与汇报重点

## 4. 如何判断 AI 生成的 Skill 是否达到企业使用标准？

至少满足：配置字段完整、输入数据可采集、分析流程可执行、输出模板稳定、样例执行结果准确。再通过业务专家评审和离线样例集验证。

## 5. 如果 AI 员工分析结果错误，企业为什么应该相信它？

企业信任的不是单次结论，而是可验证的体系：确定性指标可回溯、生成过程有约束、输出有模板、执行有评估。发现错误可修正 Skill 并重新执行，而不是黑箱式相信。

## 6. Skill、Workflow、Agent、Prompt 四者区别？

- Prompt：单次模型输入指令
- Skill：封装了 Prompt、输入契约、流程和输出模板的可复用能力
- Workflow：多个步骤按固定顺序执行的编排
- Agent：能自主选择工具和步骤完成目标的智能体

Skill 比 Prompt 更结构化，比 Workflow 更面向能力封装，是 Agent 可调用的能力单元。

## 7. 从零搭建该平台如何拆解 MVP？

1. 定义 Skill Schema
2. 跑通“自然语言 → Skill 配置”生成
3. 实现 Skill 执行与结果渲染
4. 增加前端交互闭环
5. 引入资产存储和版本管理
6. 建立样例验收与人工评审
