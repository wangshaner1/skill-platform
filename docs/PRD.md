# 产品需求文档（PRD）

产品：DataAgent Skill 平台（数花智算 · 企业 AI 员工技能平台）
版本：V1.0
更新日期：2026-08-21

## 1. 背景与业务场景

数花智算 DataAgent 产品线面向「企业 AI 经营分析员工」方向。立项来自真实客户场景：

某连锁零售集团华东大区拥有 40+ 门店，经营报告长期依赖资深店长手工整理。核心痛点：

- 资深店长经验高度个人化，离职或调动即流失，新店长上手周期 2-3 个月
- 区域经理每周花费 6-8 小时汇总各门店数据，口径不统一、横向对比失真
- 管理层希望每个门店都拥有“金牌店长”级别的经营分析能力，而不是只有个别明星店长

结论：企业需要的不是通用对话助手，而是能把岗位经验沉淀为可复用、可验证、可治理的「经验资产」的平台。

## 2. 产品定位

DataAgent Skill 平台把优秀员工的岗位经验沉淀为结构化 Skill（AI 员工能力）。业务人员用自然语言即可创建、执行、管理和发布 Skill，让 AI 员工成为企业可治理的数字劳动力。

## 3. 目标用户

| 角色 | 职责 | 核心诉求 |
|------|------|----------|
| 门店店长 / 运营人员 | 创建并使用经营分析 AI 员工 | 无需代码，一句话生成可用能力 |
| 区域经理 / 运营总监 | 统一口径、批量复盘、决策支持 | 报告口径一致、可对比、可追溯 |
| 平台管理员 | Skill 审核、发布、权限与审计 | 资产可控、操作留痕、风险可追 |

## 4. 功能需求（V1.0）

- FR1 自然语言创建 Skill：需求澄清、Skill 生成、语义校验、草稿/发布审核
- FR2 Skill 资产管理：列表、详情、版本历史、导入/导出（Markdown / JSON）
- FR3 执行分析：输入数据校验（必填/类型/异常值）、指标计算、报告生成、结论一致性检查
- FR4 示例数据：按 Skill 输入定义自动生成并缓存（按 Skill ID 键控，各版本独立）
- FR5 任务与恢复：后台任务、流式输出、断线续跑、失败一键重试
- FR6 安全与合规：输入加密存储、敏感信息脱敏、审计日志、报告复核提示
- FR7 行业模板：抖音直播、电商运营、销售经营、用户增长、零售门店五大场景

## 5. 非功能需求

- 性能：缓存命中响应 < 1 秒；首次生成 30-60 秒（流式输出）；执行任务可后台化
- 可用性：任务断线不丢失；服务重启后残留任务可识别并提示重试
- 安全：密钥不入库、输入数据加密、PII 送模型前脱敏、关键操作审计留痕
- 兼容性：模型走 OpenAI 兼容接口，可通过环境变量替换，避免供应商锁定

## 6. 成功指标（KPI）

- Skill 生成成功率 ≥ 95%（首轮通过语义校验）
- 缓存命中响应 < 1 秒；报告生成首次 ≤ 60 秒
- 区域经理报告整理工时下降 ≥ 60%
- 报告采纳率 ≥ 70%（经人工复核后直接采用）
- 缓存命中率 ≥ 40%（显著降低模型成本）

## 7. 里程碑

- M1（已交付）：核心闭环 + 五大行业场景 + 安全与信任底线
- M2：企业版（组织权限、审批流、任务队列、离线评估集）
- M3：私有化部署与多租户
