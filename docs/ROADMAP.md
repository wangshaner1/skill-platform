# 产品路线图

## V1.0（已交付）

- 自然语言创建 AI 员工：澄清 → 生成 → 语义校验 → 草稿/发布
- 五大行业场景模板与执行闭环
- 流式输出、后台任务与断线续跑
- Redis 缓存降本、示例数据自动匹配
- 安全与信任底线：加密、脱敏、审计、质量门禁、一致性检查

## V1.5（规划中）

- 正式任务队列（Celery/RQ）与多实例高可用
- 模型降级与多供应商路由
- 执行结果缓存（数据哈希级复用）
- 离线评估集接入 CI，发版自动跑分

## V2.0（企业版）

- 组织架构、角色权限、审批流与配额
- Skill 模板市场与行业解决方案库
- PostgreSQL 替换 SQLite，多租户隔离
- 成本核算与用量报表

## V3.0（规模化）

- 语义缓存（相似需求复用，需人工确认）
- 智能推荐：根据业务角色推荐可用 Skill
- 私有化一体机与本地模型适配
