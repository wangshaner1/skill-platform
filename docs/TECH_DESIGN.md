# 技术方案说明（生产级）

产品：DataAgent Skill 平台
版本：V1.0

## 1. 系统架构

```text
客户端（浏览器 / 企业系统）
        │ HTTPS / JSON / SSE
        ▼
接入与任务层
 ├─ Skill 生成 / 执行引擎
 ├─ 后台任务（断线续跑）
 └─ 需求澄清 / 语义校验
        ▼
模型与规则层
 ├─ LLM 网关（OpenAI 兼容，可降级替换）
 └─ 指标引擎（规则优先，27+ 指标）
        ▼
数据层
 ├─ 业务库（SQLite → PostgreSQL）
 ├─ Redis（缓存 / 任务状态）
 └─ 对象存储（报告与素材，生产）
```

## 2. 核心模块

- Skill 生成引擎：LLM 生成 7 要素配置，Pydantic Schema + 语义校验，失败自动重试
- 任务引擎：后台线程 + 任务表，进度落库，SSE 订阅；生产迁移 Celery/RQ
- 指标引擎：指标口径库统一公式，规则引擎计算，LLM 只做解读与归因
- 质量与一致性：数据质量门禁（必填/类型/异常值）、结论-指标一致性检查
- 缓存：需求哈希缓存（Redis）、示例数据按 Skill ID 键控
- 安全：输入加密（Fernet）、PII 脱敏、审计日志（需求只存哈希）

## 3. 数据设计

主要表：

- `skills`：Skill 资产（id、名称、完整配置 JSON、版本、状态、创建/更新时间）
- `skill_versions`：版本历史（每次保存自动升版本并保留快照）
- `tasks`：后台任务（类型、输入数据加密存储、状态、进度、结果、错误）

加密说明：`tasks.input_data` 使用 Fernet 加密后落库，读取时解密；密钥文件不入版本库。

## 4. 高可用与容灾

- 应用无状态，可多实例水平扩展；任务队列外置后支持多节点消费
- 数据库主从 + 定期备份；Redis 开启 AOF/RDB 持久化，生产配置主从与哨兵
- 服务重启：残留 running 任务自动标记失败，前端提示一键重试
- Skill 版本化，支持回滚与灰度发布

## 5. 安全设计

- 传输层 TLS；存储层字段加密；模型调用前 PII 脱敏
- 关键操作（生成、发布、导入）审计留痕
- 草稿/发布审核：未发布 Skill 不允许作为正式资产使用
- 生产待办：KMS 密钥托管、IAM 与租户隔离、敏感数据分级

## 6. 可观测性

- `/api/stats`：LLM 调用次数、缓存命中/未命中、缓存命中率、各接口调用量
- 请求耗时日志；生产增加失败率、延迟、token 成本告警

## 7. 性能与容量

- 缓存命中响应 < 1 秒；首次生成 30-60 秒（流式）
- 单实例建议任务并发上限 5-10，超限排队；生产按业务量评估扩容

## 8. 部署

- 开发环境：`docker compose up --build`（web + redis）
- 生产：K8s 多副本 + 托管 PostgreSQL + Redis 集群 + 对象存储
- 配置：`QWEN_API_KEY`、`QWEN_BASE_URL`、`QWEN_MODEL`、`REDIS_URL`

## 9. 发布与回滚

- Skill 每次修改自动生成新版本，历史可查可回滚
- 发布前跑离线评估集（带标准答案），通过后灰度上线
