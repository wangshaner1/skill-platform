# 客户常见问题（FAQ）

## 1. 数据安全如何保障？

输入数据在服务端加密存储，送模型前自动脱敏（手机号、身份证、邮箱、银行卡等），关键操作写入审计日志（需求只记录哈希）。支持私有化部署，把模型和数据放在企业自己的环境内。

## 2. 和 ChatGPT 有什么区别？

ChatGPT 是通用对话助手，不懂企业数据口径；DataAgent Skill 平台把岗位经验沉淀为可复用、可验证、可治理的 Skill 资产，输出有固定格式、指标有统一口径、结论有数据依据。

## 3. 和 BI / Excel 有什么区别？

BI 和 Excel 提供看板与报表，仍需人来解读和写结论；Skill 平台自动完成“数据 → 指标 → 洞察 → 行动建议”的完整闭环，店长直接拿到可执行的复盘报告。

## 4. 使用成本如何？

按模型调用量计费，相同需求命中缓存后秒回、几乎零成本。平台内置成本统计接口，可按团队/业务线核算。

## 5. 上线周期多长？

标准行业模板（门店、直播、电商、销售、用户增长）1-2 周即可投入使用；需要私有化或对接企业系统的，一般 4-8 周。

## 6. 支持哪些行业？

当前覆盖零售门店、直播电商、传统电商、销售团队、用户增长等经营分析场景；新场景可通过自然语言快速扩展。

## 7. 如何验证效果？

平台提供离线评估集与人工复核流程：每个 Skill 带标准答案样例，发布前自动跑分；上线后跟踪使用率、报告采纳率与节省工时。
